# 📺 RH番剧记录系统 (RH Bangumi Tracker)

基于 **Vue 3 + Vite 5** 构建的本地番剧追踪与记录系统，UI 采用仿哔哩哔哩（Bilibili）的二次元清爽设计。通过接入 **Bangumi API** 实时获取海量番剧数据，提供一键隐形后台运行、系统托盘管理、追番进度追踪、新番日历、个人荐番墙等丰富功能。

---

## ✨ 核心特性

- 🚀 **100% 隐形后台运行**
  - 提供了编译好的原生启动器 `启动RH番剧记录.exe` 与 `启动RH番剧记录.vbs` 脚本，运行后**没有任何命令行黑框闪烁**。
  - 自动在系统后台静默拉起服务器，不占用任务栏。
- 📺 **Windows 系统托盘常驻**
  - 启动后常驻右下角系统托盘（粉底白字 **RH** 定制图标）。
  - 支持双击打开浏览器、右键菜单（打开浏览器/退出系统）。
  - 退出托盘时自动强力清除后台所有 Vite/Node 占用进程，不占系统资源。
- 📅 **新番每日放送**
  - 首页集成 Bangumi 每日放送日历，按星期自动切换，当天放送番剧高亮显示，精彩不容错过。
- 🔍 **多维智能番剧搜索**
  - 整合关键词搜索、年份段筛选、季度过滤以及国家/地区精细检索。
  - 支持**无级增量时间轴加载**，以“番图表（时间轴）”或“卡片网格”双模式展示，加载快速流畅。
- 📝 **看番进度与打分管理**
  - 分类归档（在看、想看、看过、抛弃），一键 `+1集` 快捷推进。
  - 鲁棒的话数计算：智能适配非常规起始集数偏移（如第二季从第14话起算），完美计算百分比和高亮。
- 👍 **个人专属“荐番墙”**
  - 支持创建多个自定义文件夹（如“神作推荐”、“胃痛神作”等）。
  - 拖拽式交互：支持直接将番剧卡片**拖放**入左侧侧边栏的目标文件夹进行归类。
  - 📷 **海报截图分享**：一键将荐番墙高清输出为 PNG 海报，方便在社交平台分享。
  - 💾 **导入/导出**：支持 JSON 备份，以及精心设计的 **150 字符极短分享编码**，联网自动拉取，快速同步数据。

---

## 🛠️ 技术栈

- **前端框架**：Vue 3 (Composition API / `<script setup>`)
- **路由管理**：Vue Router 4
- **构建工具**：Vite 5 (本地开发服务器兼图片反向代理)
- **样式方案**：Vanilla CSS (B站风格设计系统，完美适配深浅色主题)
- **启动层**：PowerShell (Windows Forms) + C# (.NET Framework 4.0+) / VBScript

## 🚀 快速开始

### 准备工作

1. 确保你的电脑上安装了 [Node.js](https://nodejs.org/)（建议版本 18 或更高）。
2. 将本项目克隆或下载到本地任意文件夹。

### 运行方式 (Windows)

你只需双击运行根目录下的以下任意一个文件即可启动系统（首次启动会自动安装依赖）：

*   **方式一（最推荐）**：双击 [启动RH番剧记录.exe](启动RH番剧记录.exe)。
    *   *特点：完全静默，不闪黑框，直接启动，并在右下角系统托盘常驻。*
*   **方式二（BUG待修复）**：双击 [启动RH番剧记录.vbs](启动RH番剧记录.vbs)。
    *   *特点：效果同 EXE，完全静默运行。*
*   **方式三**：双击 [启动RH番剧记录.bat](启动RH番剧记录.bat)。
    *   *特点：会有 50 毫秒的命令行窗口一闪而过。保留一个PowerShell窗口*

启动成功后，浏览器会自动打开 `http://localhost:5173/`。

## ⚙️ 认证配置 (Token 设置)

为了在详情页拉取特定剧集，建议在首页配置你的 **Bangumi API Token**：
1. 打开系统首页，点击 **API 设置** 或下拉到底部的 **设置** 卡片。
2. 点击 API Token 输入框旁的链接前往 [Bangumi 官网 Token 生成页面](https://next.bgm.tv/demo/access-token)（需登录你的 Bangumi 账号）。
3. 复制生成的 Personal Access Token 并粘贴至系统的 API 设置中保存即可。
