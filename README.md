# 📺 RH番剧记录系统 (RH Bangumi Tracker)

一个专为动漫爱好者设计的本地番剧记录与追踪工具。采用清爽、美观的二次元视觉设计，帮助你轻松打理日常追番生活、整理推荐列表，并与好友分享你的动漫喜好。

---

## 💡 功能说明

本系统旨在解决日常追番过程中的痛点，为你提供以下实用功能：

*   **📅 每日新番放送提醒**
    *   自动同步最新的新番放送时间表，按星期进行清晰展示。
    *   当天更新的番剧会自动高亮显示，让你第一时间掌握更新动态，不再错过任何一部新番。
*   **📺 个人看番进度管理**
    *   支持对番剧进行分类整理（想看、在看、看过、抛弃），一键推进 `+1集` 进度。
    *   智能适配非标起始集数的番剧（例如从第14话起算的分割单季或第二季），完美计算和展示你的追番进度百分比。
*   **🔍 智能番剧搜索与筛选**
    *   支持通过年份范围、放送季度、国家/地区等多个维度精细化过滤海量番剧。
    *   提供“卡片网格”与“时间轴列表”两种浏览模式，不论是寻找经典老番还是当季热门，都能快速定位。
*   **🎨 专属荐番墙与拖拽归类**
    *   支持自由创建自定义主题文件夹（如“神作推荐”、“致郁神作”、“胃痛胃药”等）。
    *   支持简单直观的**鼠标拖拽交互**，直接将番剧卡片拖入左侧对应的分类文件夹中，整理番剧如同整理桌面般轻松。
*   **📷 精美海报截图分享（有BUG）**
    *   可一键将你的个人“荐番墙”或推荐列表导出为高清的 PNG 图片海报，方便保存至本地，或直接分享到社交平台与同好交流。
    *   支持将你的番剧列表生成一段仅 150 字符的极短分享编码，其他用户复制该编码即可联网同步加载你的推荐内容。
*   **🍀 无干扰后台运行与系统托盘管理**
    *   专为 Windows 桌面环境定制，启动后没有任何黑框和命令行窗口干扰，自动在后台静默运行。
    *   常驻任务栏右下角系统托盘（带有粉底白字 **RH** 的定制图标），支持双击快速在浏览器中打开系统，右键一键安全退出并自动彻底清理后台资源占用。

## 🚀 快速开始

### 准备工作

1. 确保你的电脑上已安装 [Node.js](https://nodejs.org/)（建议版本 18 或更高）。
2. 将本项目克隆或下载到本地任意文件夹。

### 运行方式 (Windows)

你只需双击运行根目录下的以下任意一个文件即可启动系统（首次启动会自动安装依赖）：

*   **方式一（最推荐）**：双击运行 [启动RH番剧记录.exe](file:///d:/AZhiZhi/AI/RH_bangumi/启动RH番剧记录.exe)。
    *   *特点：完全静默启动，不闪烁任何命令行黑框，并在右下角系统托盘常驻。*
*   **方式二（有BUG）**：双击运行 [启动RH番剧记录.vbs](file:///d:/AZhiZhi/AI/RH_bangumi/启动RH番剧记录.vbs)。
    *   *特点：同样完全静默无黑框运行。*
*   **方式三**：双击运行 [启动RH番剧记录.bat](file:///d:/AZhiZhi/AI/RH_bangumi/启动RH番剧记录.bat)。
    *   *特点：仅有短暂的命令行窗口闪过。*

启动成功后，浏览器会自动打开系统页面。

## ⚙️ 认证配置 (Token 设置)

为了正常拉取番剧的具体剧集和更新信息，建议在首次使用时配置你的个人 **Bangumi 认证凭证**：
1. 打开系统首页，点击 **API 设置** 或下拉到底部的 **设置** 面板。
2. 点击 API Token 输入框旁的链接前往 [Bangumi 官网 Token 生成页面](https://next.bgm.tv/demo/access-token)（需登录你的 Bangumi 账号）。
3. 复制生成的 Personal Access Token 并粘贴至系统的 API 设置中保存即可。
